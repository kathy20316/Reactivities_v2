**Activities Manager**

**Overview**

Activities Manager is a web application that allows users to create, view, edit, and delete activities. Each activity includes details such as the name, timestamp, location, category, and an associated image.

****Features****

✅ Create Activities: Add new activities with relevant details. 

✅ View Activities: Display a list of past and future activities. 

✅ Edit Activities: Modify activity details. 

✅ Delete Activities: Remove unwanted activities.

✅ Categorization: Activities are labeled with categories like culture, drinks, and travel.

**Technologies Used**

* Frontend: Typescript, React.js, HTML/CSS/Javascript

* Backend: C#, APS.NET Core

* Database: MySQL

* Version Control: Git & GitHub

* Deployment: GitHub Actions

**Installation**

**Prerequisites**

🚀 .NET SDK (ASP.NET Core)

🚀 Node.js and npm

🚀 PowerShell (for automation scripts)

**Steps**

**Clone the Repository**
  ```
  git clone https://github.com/kathy20316/Reactivities_v2
  
  cd reactivities/backend
  ```
**Build and run Backend**
  ```
  dotnet restore
  
  dotnet build
  
  dotnet run
  ```
**Setup Frontend**
```
cd frontend

npm install

npm start
```
**Access the Application**

Open http://localhost:3000 in your browser.

**Usage**

💻 Click **Create Activity** to add a new activity.

💻 Use the **View button** to see activity details.

💻 Edit activities using the **Edit** button.

💻 Delete activities permanently using the **Delete** button.
